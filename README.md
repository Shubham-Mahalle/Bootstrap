# Student Task Portal

Student Task Portal is a beginner-level web application built to practice **HTML5, CSS3, Bootstrap 5, and JavaScript fundamentals**.

The project allows students to create an account, log in, view their profile, and manage their study tasks. Student accounts and tasks are stored in the browser using **Local Storage**.

## Project Overview

Student Task Portal is designed as a simple student workspace where users can:

- Create a student account
- Log in using email and password
- View student profile information
- Add study tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Store accounts and tasks using Local Storage
- Log out from the portal

The project focuses on practicing **DOM manipulation, events, forms, arrays, objects, functions, Local Storage, and Bootstrap components**.

## Features

### 1. Student Registration

Users can create an account by providing:

- Student name
- Email address
- Password
- Age
- Course
- Gender
- Skills

The registration form also performs basic HTML form validation.

### 2. Login System

Registered students can log in using their email and password.

The application checks the stored student accounts and displays an error message when the credentials are incorrect.

### 3. Student Profile

After logging in, students can open **My Profile** to view:

- Name
- Email
- Age
- Course
- Gender
- Selected skills

### 4. Task Manager

Students can manage their study tasks.

Available operations include:

- Add a task
- Complete a task
- Undo a completed task
- Edit a task
- Delete a task

Completed tasks are displayed with a line-through style.

### 5. Local Storage

The project uses browser `localStorage` to store:

- Student account information
- Student tasks

Each student's tasks are stored separately using their email address.

### 6. Bootstrap UI

The project uses **Bootstrap 5** for:

- Navbar
- Cards
- Forms
- Buttons
- Alerts
- Badges
- Modal
- Navigation pills
- Responsive layout
- Flexbox utility classes
